\# ワンコインデコーダX



ワンコインデコーダXは、WCH CH32V003 マイコンを使用した鉄道模型向け DCC デコーダです。



低コストで導入できることを重視しつつ、実用的な走行性能と各種機能の実現を目指して開発しています。



\## 特徴



\- CH32V003 を採用

\- NMRA DCC規格対応

\- モータPWM制御

\- 各種CV設定対応

\- オープンソースソフトウェア
