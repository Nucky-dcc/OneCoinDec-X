1. 概要 (Overview)
------------------------------------------------------------------------------
「ワンコインデコーダＸ」は、安価で高性能なWCH社製高電圧?低ピン数RISC-Vマイコン
「CH32V003」を採用した、自作DCCデコーダプロジェクトです。

1つのソースコード資産から、コンパイルスイッチ（マクロ定義）を切り替えるだけで、
以下の4種類の異なるターゲットハードウェア向けファームウェアを出力できます。

TARGET_8PIN_LOCO  : 8ピンマイコンを使用した超小型車両用モーターデコーダ
TARGET_20PIN_LOCO : 20ピンマイコンを使用したBEMF対応フルスペックデコーダ
TARGET_8PIN_FUNC  : モーター出力を省き4出力を確保したファンクションデコーダ
TARGET_8PIN_POINT : ポイントマシン専用アクセサリーデコーダ

2. 主な機能と特徴 (Features)
------------------------------------------------------------------------------
【車両用（LOCO）共通機能】

?NMRA規格準拠DCC信号解析
  （ショートアドレス／ロングアドレス自動判定）

?3点速度カーブ制御
  （Vstart, Vmid, Vhigh）

?キックスタート機能

?モメンタム（加減速）制御

?進行方向反転時の自動一時停止
  （反転ポーズ機能）

?可聴域外PWM周波数対応
  （32kHz、8kHz、2kHz、500Hz）

?ファンクションマッピング
  （F0～F12対応）

?CV8への「8」書き込みによるファクトリーリセット

?両極性Fxモード
  （CV30 = 2）


【20ピン車両用（TARGET_20PIN_LOCO）専用機能】

?BEMF（逆起電力）検出

?PID制御によるロードコンペンセーション

?BEMFカットアウト機能


【ポイントデコーダ（TARGET_8PIN_POINT）専用機能】

?ソレノイド焼損防止タイマー

?PWM出力制限機能

?ガードタイム機能

?前回開通方向の自動記憶／復元

4. 開発環境 ＆ コンパイル方法
   (Development & Compilation)
------------------------------------------------------------------------------
本ソフトウェアは WCH 社公式統合開発環境

    MounRiver Studio

を使用してビルドおよび書き込みを行います。


【ビルド手順】

1. MounRiver Studio を起動

2. decoder_config.h を開く

3. ターゲットを選択

      #define TARGET_8PIN_LOCO

      //#define TARGET_20PIN_LOCO
      //#define TARGET_8PIN_FUNC
      //#define TARGET_8PIN_POINT

4. モータドライバ種別を選択

   TB67H450系（Low有効）
      #define USE_TB67H450

   BD6231系（High有効）
      #define USE_BD6231

5. Build実行

6. WCH-LinkE を接続

7. Download実行


5. 主要CV値一覧
   (Key Configuration Variables)
------------------------------------------------------------------------------
本デコーダは CV1～CV64 に対応しています。


【車両?ファンクション共通】

CV1
  ショートアドレス
  初期値 : 3
  設定範囲 : 1～127

CV2
  Vstart（起動電圧）
  初期値 : 0
  設定範囲 : 0～255

CV3
  加速率（モメンタム）
  初期値 : 0
  設定範囲 : 0～255

CV4
  減速率（モメンタム）
  初期値 : 0
  設定範囲 : 0～255

CV5
  Vhigh（最高電圧）
  初期値 : 255
  設定範囲 : 0～255

CV6
  Vmid（中間電圧）
  初期値 : 0
  設定範囲 : 0～255
  0または1の場合は直線補間

CV7
  デコーダバージョン
  初期値 : 10
  読み取り専用

CV8
  メーカーID
  初期値 : 156（Web Nucky）

  ※「8」を書き込むとファクトリーリセット

CV9
  モータPWM周波数
  初期値 : 0

    0 = 32kHz
    1 = 8kHz
    2 = 2kHz
    3 = 500Hz

CV10
  BEMFカットアウト
  初期値 : 64

CV17
  ロングアドレス上位
  初期値 : 192

CV18
  ロングアドレス下位
  初期値 : 128

CV19
  コンシストアドレス
  初期値 : 0

CV29
  コンフィグレーション
  初期値 : 2

    bit0 = 方向反転
    bit1 = 28/128ステップ
    bit5 = ロングアドレス有効

CV30
  両極性Fxモード
  初期値 : 0

    0 = 通常動作
    2 = モータ出力をF0転極回路として使用

CV33～46
  ファンクションマッピング

  初期値

    CV33 = 1
    CV34 = 2
    CV35 = 4
    CV36 = 8
    CV37 = 16
    CV38 = 32

CV47
  キックスタート持続時間
  初期値 : 0

    0     = 無効
    1～255 = 10ms～2550ms

CV48
  キックスタート強度
  初期値 : 0
  設定範囲 : 0～255

CV50
  BEMF有効／無効
  初期値 : 0

    0 = 無効
    1以上 = 有効

CV51
  Pゲイン
  初期値 : 10

CV52
  Iゲイン
  初期値 : 3

CV53
  ブランキングタイム
  初期値 : 14

    14 = 140us

CV54
  BEMFサンプリング周期
  初期値 : 20

    20 = 20ms


【ポイントデコーダ専用】

CV1
  アクセサリーアドレス下位
  初期値 : 129

CV2
  アクセサリーアドレス上位
  初期値 : 248

CV3
  通電時間
  初期値 : 5

    50ms
    （10ms単位）

CV4
  出力保持設定
  初期値 : 1

CV5
  反転ディレイ
  初期値 : 1

CV6
  PWM出力強度
  初期値 : 127

CV9
  ガードタイム
  初期値 : 5

    500ms
    （100ms単位）

CV64
  開通方向記憶
  システムが自動管理
